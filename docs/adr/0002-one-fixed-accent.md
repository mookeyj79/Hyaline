# One fixed accent

Hyaline ships a single accent blue rather than a selectable set like Catppuccin's accent flavors. Selectable accents would multiply every port's output by the number of accents, need contrast checks per accent and per `on_accent`, and break the rule that Accent and Blue share a hue. Sameness across ports wins over personal choice. Adding a set later would be a minor palette change, so this can be revisited without breaking ports.
